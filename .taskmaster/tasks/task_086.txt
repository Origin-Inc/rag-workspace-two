# Task ID: 86
# Title: Enable Direct File Upload to Editor with Automatic SpreadsheetBlock Creation
# Status: pending
# Dependencies: 65, 66
# Priority: medium
# Description: Implement direct CSV/Excel file upload functionality on the editor page that automatically creates editable SpreadsheetBlocks through toolbar button, drag-and-drop, or slash command.
# Details:
Create a comprehensive file upload system leveraging existing infrastructure:

1. **File Upload UI Integration**:
   - Add 'Upload Spreadsheet' button to editor toolbar
   - Implement drag-and-drop zone overlay on editor
   - Add /upload slash command to SlashMenu component
   - Use FileUploadService for validation and Supabase Storage uploads

2. **Server-Side Processing Pipeline**:
   - Create file-parser.server.ts using PapaParse (CSV) and SheetJS (Excel)
   - Build file-to-spreadsheet-block.server.ts for data transformation
   - Implement upload action handler in editor.$pageId.tsx using unstable_parseMultipartFormData
   - Create DataFile record and transform to SpreadsheetBlockContent format

3. **Client-Side Optimization**:
   - Implement Web Worker parsing for files >5MB via file-parser.client.ts
   - Add optimistic UI with skeleton SpreadsheetBlock appearance
   - Use useProgressiveFileUpload hook for progress indicators
   - Handle files <2MB on server, >2MB with Web Worker to prevent UI freezing

4. **Block Integration**:
   - Insert SpreadsheetBlock into Page.blocks JSONB using established patterns
   - Ensure proper column type detection (text/number/boolean/date)
   - Implement block stacking below existing content
   - Return block data for immediate editor update

5. **Error Handling & Performance**:
   - Validate file types (.csv, .xlsx, .xls only) and size limits
   - Show descriptive error messages for failures
   - Target <2s for small files, <5s for medium files, <15s for large files
   - Ensure skeleton appears in <100ms for instant feedback

Technical approach follows 'Upload First, Parse Smart, Create Fast' pattern to bypass Vercel 4.5MB limits while maintaining responsive UX.
