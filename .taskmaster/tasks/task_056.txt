Metadata Structure:
```typescript
// ChatMessage.metadata
{
  queryIntent: 'data_visualization' | 'general_chat',
  generatedSQL: string,
  queryResultsSummary: { rowCount, columns, sampleRows },
  generatedChart?: { type, data, title, confidence },
  generatedTable?: { columns, rows, title }
}

// Block metadata in Page.blocks
{
  sourceMessageId: string,
  provenance: {
    generatedBy: { model, version, provider },
    generatedAt: ISO_timestamp,
    source: { type: 'chat_query', sourceId, originalQuery },
    confidence: number,
    dataProvenance: { database, tables, queryHash }
  }
}
```

Performance Considerations:
- Keep metadata < 10KB for sub-100ms queries
- Results > 2KB trigger TOAST storage (2-10x slower)
- Use fetch-update-save pattern for Prisma JSONB updates
- Simple block positioning: nextY = max(blocks.map(b => b.y + b.height))
