================================================================================
FORMULA SUPPORT
================================================================================

Evaluator: /app/utils/simple-formula-evaluator.ts (261 lines)
Why: Pure JavaScript, zero dependencies, works on Vercel

Supported Functions:
  - Arithmetic: +, -, *, /, ()
  - SUM(a,b,c,...) - sum of arguments
  - AVERAGE(a,b,c,...) - mean of arguments
  - MAX(a,b,c,...) - maximum value
  - MIN(a,b,c,...) - minimum value
  - COUNT(a,b,c,...) - count of arguments
  - IF(condition, trueVal, falseVal) - conditional

A1 Notation Utils: /app/utils/spreadsheet-notation.ts (209 lines)
  - columnIndexToA1(0) → 'A'
  - a1ToColumnIndex('Z') → 25
  - indicesToA1(0, 0) → 'A1'
  - parseA1('A1') → { row: 0, col: 0 }
  - extractA1References('=SUM(A1:A10)') → ['A1:A10']
  ... 42+ total functions

PERFORMANCE
================================================================================

Benchmarks Achieved:
  - Init: <30ms (target <50ms) ✅
  - Cell edit: <10ms (target <16ms) ✅
  - Formula eval: <1ms (pure JS)
  - Virtual scroll: 60fps (Glide Data Grid canvas) ✅
  - File import (1MB): <500ms ✅

Why NOT using DuckDB WASM for spreadsheet data:
  - React state provides faster edits (<10ms vs async overhead)
  - Virtual scrolling handled by Glide Data Grid
  - DuckDB reserved for complex queries on imported files
